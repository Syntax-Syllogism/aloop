# Contributing to aloop

Thanks for your interest in aloop. This is a hobbyist project, and all kinds of contributions are welcome.

## Ways to help

- **Report a bug.** Open an issue with a clear description and the steps to reproduce it.
- **Suggest a feature.** Open an issue to talk it through first.
- **Send a pull request.**
  1. Fork the repository and create a branch.
  2. Make your change, with clear code and comments where they help.
  3. Run `npm test` and make sure it passes.
  4. Open a pull request that describes what you changed and why.

## Development setup

See the [README](README.md#development) to set up the project locally.
